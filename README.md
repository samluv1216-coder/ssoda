# 🏹 쏘다 (SSODA)

> AI에게 딱 맞게 다듬어, 쏘다

선생님의 AI 작업을 돕는 웹앱입니다. 설치·로그인 없이 브라우저에서 바로 씁니다.

| 탭 | 내용 |
|---|---|
| 🎯 프롬프트 만들기 | 양식을 고르고 빈칸을 채우면 역할·요청·조건·결과 형식이 갖춰진 프롬프트를 만들어 줍니다. 복사한 뒤 재미나이·챗GPT·Claude를 바로 열 수 있습니다 |
| 📄 문서 → 마크다운 | PDF·한글(HWPX)·워드(DOCX)·파워포인트(PPTX)·엑셀(XLSX·XLS)·CSV·사진을 AI가 읽기 좋은 마크다운으로 바꿉니다. 파일은 서버로 보내지 않습니다. 결과는 **「이 자료로 프롬프트 만들기」** 버튼으로 프롬프트의 참고 자료로 넘길 수 있습니다 |
| 🔒 개인정보 가리기 | 이름·전화·이메일·학년반번호를 가명(학생A, [전화1])으로 바꿔 AI에 보내고, AI 답을 원래 이름으로 되돌립니다. 조사(은/는, 이/가, 과/와)도 받침에 맞게 고칩니다. 대응표는 브라우저에만 저장 |
| 📝 AI 답 → 한글·엑셀 | AI가 준 마크다운 답을 **한글 문서(.hwpx)** 로 저장하거나, 서식을 살려 한글에 붙여 넣을 수 있게 복사합니다. 답 속의 **표는 엑셀(.xlsx)** 로 저장합니다(표마다 시트 하나, 숫자·퍼센트는 숫자 칸으로) |

## 프롬프트 양식 (15종)
- 📚 수업: 수업 지도안, 학습지·활동지, 지문·읽기 자료
- 📝 평가: 평가 문항, 채점 기준표(루브릭)
- 🗂️ 업무: 가정통신문·안내문, 공문·기안문 초안, 회의록 정리, 메일·문자 다듬기
- 🧑‍🎓 학생 기록: 세특·행발 문구, 상담 기록 정리 (개인정보 안내 표시)
- 🎨 이미지·글: 이미지 만들기, 내용(글) 만들기 (쏙의 프롬프트 생성기를 옮겨 넓힘)
- 📄 자료 활용: 문서 요약, 문서로 수업자료 만들기 (참고 자료 필수)

**양식 추가하기**: `js/templates.js`의 `TEMPLATES` 배열에 항목을 하나 넣으면 입력 화면과 프롬프트가 자동으로 만들어집니다.

## 그 밖의 기능
- ✂️ 긴 프롬프트·자료를 여러 번에 나눠 보내기 ("받았어요 (1/3)"만 답하도록 안내 포함)
- ↪ 답을 받은 뒤 이어서 보낼 후속 요청 8종 (더 쉽게, 표로 정리, 사실 점검 …)
- 학교급·학년·과목은 한 번 입력하면 모든 양식에 공통으로 적용
- ⭐ 자주 쓰는 입력 저장/불러오기 (이 브라우저에만 저장)
- 주민번호·전화번호·이메일·학년반번호가 들어가면 경고 표시

## 구조
- `index.html` — 화면 (탭 2개)
- `js/app.js` — 탭 전환·알림·복사
- `js/templates.js` — 프롬프트 양식 데이터
- `js/prompt.js` — 프롬프트 입력 화면과 조립
- `js/pdf2md.js` — PDF → 마크다운 변환 엔진 (pdf.js 3.11.174)
- `js/ocr.js` — 사진·스캔 PDF 글자 인식
- `js/sheet.js` — 엑셀·CSV ↔ 마크다운 표 (SheetJS 0.18.5, 필요할 때만 불러옴)
- `js/office2md.js` — HWPX·DOCX·PPTX → 마크다운
- `js/privacy.js` — 개인정보 가리기·되돌리기
- `js/convert.js` — 변환 탭 화면
- `js/hwpx.js` — 마크다운 → 한글(HWPX) 변환 엔진 (JSZip 3.10.1)
- `js/tohwp.js` — AI 답 → 한글 탭 화면
- `css/styles.css` — 쏙(SSOK)과 같은 톤

## 문서 변환 한계
- HWPX: 글자 크기로 제목, 문단 모양의 자동 번호·글머리표와 □○―· 기호를 목록으로, 1칸짜리 표(글상자)는 본문으로
- DOCX: 스타일(제목 1…)과 번호 매기기·들여쓰기로 목록 단계, 셀 합치기는 빈칸
- PPTX: 발표 순서대로 제목·본문·표·발표자 노트, 그림으로만 된 슬라이드는 빼고 알려 줌
- 예전 HWP(바이너리)는 지원하지 않음 → 한글에서 HWPX로 저장
- 엑셀·CSV: 시트마다 표 하나, 빈 열 제거, 날짜는 2026-11-20 형식, 맨 위 제목 줄은 표 제목으로. EUC-KR CSV(나이스 등)도 자동 인식
- 사진(PNG·JPG)과 스캔 PDF는 글자 인식(OCR, tesseract.js 5.1.1 한국어+영어)으로 읽음. 브라우저 안에서 처리하고, 처음 한 번 인식 데이터(약 10MB)를 받음. 줄 위치·크기로 제목·문단·번호 목록을 복원

### PDF
- 스캔본(이미지 PDF)은 글자를 못 읽음 → OCR/AI 변환 필요
- 여러 줄짜리 칸·칸 합치기가 있는 표는 거칠게 나옴, 그림·수식은 빠짐

## 한글(HWPX) 변환
- A4, 여백 좌우 30mm · 위 20mm · 아래 15mm, 본문 함초롬바탕(또는 돋움) 10~12pt, 줄 간격 160%
- 첫 `#` 제목은 가운데 큰 제목, 이후 제목은 단계별 크기의 함초롬돋움 굵게
- 표는 실제 한글 표(테두리, 첫 줄 회색 배경), 목록은 •◦▪ / 1. 2. 3. 과 들여쓰기
- 그림·수식은 빠지고, 셀 합치기가 있는 표는 단순한 표로 만들어짐
- 한컴오피스 한글(Mac 12.30)에서 열림 확인
