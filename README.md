# 🏹 쏘다 (SSODA)

> AI에게 딱 맞게 다듬어, 쏘다

선생님의 AI 작업을 돕는 웹앱입니다. 설치·로그인 없이 브라우저에서 바로 씁니다.

| 탭 | 내용 |
|---|---|
| 🎯 프롬프트 만들기 | 양식을 고르고 빈칸을 채우면 역할·요청·조건·결과 형식이 갖춰진 프롬프트를 만들어 줍니다. 복사한 뒤 재미나이·챗GPT·Claude를 바로 열 수 있습니다 |
| 📄 PDF → 마크다운 | PDF를 AI가 읽기 좋은 마크다운으로 바꿉니다. 파일은 서버로 보내지 않습니다. 결과는 **「이 자료로 프롬프트 만들기」** 버튼으로 프롬프트의 참고 자료로 넘길 수 있습니다 |

## 프롬프트 양식 (15종)
- 📚 수업: 수업 지도안, 학습지·활동지, 지문·읽기 자료
- 📝 평가: 평가 문항, 채점 기준표(루브릭)
- 🗂️ 업무: 가정통신문·안내문, 공문·기안문 초안, 회의록 정리, 메일·문자 다듬기
- 🧑‍🎓 학생 기록: 세특·행발 문구, 상담 기록 정리 (개인정보 안내 표시)
- 🎨 이미지·글: 이미지 만들기, 내용(글) 만들기 (쏙의 프롬프트 생성기를 옮겨 넓힘)
- 📄 자료 활용: 문서 요약, 문서로 수업자료 만들기 (참고 자료 필수)

**양식 추가하기**: `js/templates.js`의 `TEMPLATES` 배열에 항목을 하나 넣으면 입력 화면과 프롬프트가 자동으로 만들어집니다.

## 그 밖의 기능
- 학교급·학년·과목은 한 번 입력하면 모든 양식에 공통으로 적용
- ⭐ 자주 쓰는 입력 저장/불러오기 (이 브라우저에만 저장)
- 주민번호·전화번호·이메일·학년반번호가 들어가면 경고 표시

## 구조
- `index.html` — 화면 (탭 2개)
- `js/app.js` — 탭 전환·알림·복사
- `js/templates.js` — 프롬프트 양식 데이터
- `js/prompt.js` — 프롬프트 입력 화면과 조립
- `js/pdf2md.js` — PDF → 마크다운 변환 엔진 (pdf.js 3.11.174)
- `js/convert.js` — 변환 탭 화면
- `css/styles.css` — 쏙(SSOK)과 같은 톤

## PDF 변환 한계
